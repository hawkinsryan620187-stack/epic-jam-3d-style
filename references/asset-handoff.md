# 资产交付与复核

本包制定风格和生产目标，不包含已经验收的 3D 模型，也未针对某一建模服务做生成成功率测试。获得成品后按它的实际用途检查，不把提示词里的“game-ready”当作已经完成验收。

## 请求时只补充影响本件资产的信息

- 资产名称、用途与主要剪影；已有设计图优先。
- 是静态摆件、可开合/旋转道具，还是需要绑定动画的角色。
- 有明确需求时填写尺寸、模型格式、面数/贴图预算；未确定则标为待对齐，风格设计可先继续。

常见交付格式可以是 FBX 或 GLB，选择制作组和实际工具共同支持的格式；保留可编辑源文件（如果实际存在）。绑定、动画、材质通道和导入选项受软件链路影响，交付前用项目实际配置验证。

## 统一风格复核

先用统一中性白光和一致曝光比对，不为评审单件资产加入夕阳、雾、景深或额外色调滤镜。

| 检查项 | 可通过表现 | 需要修正的例子 |
|---|---|---|
| 剪影与主次 | 目标视距下主体、功能部件和角色身份可辨识 | 灯罩、手柄或角色四肢粘成一团 |
| 分面尺度 | 大切面清楚、曲面概括得当，与参考资产量级相近 | 树冠像细碎水晶，桌子却光滑如塑料 |
| 细节密度 | 少量结构细节服务识别，同级物体复杂度相近 | 普通柜子布满螺钉、刻花和写实木纹 |
| 材质 | 木、石、布、金属有可解释的区别 | 所有表面都是同一种光亮塑料 |
| 色彩 | 主辅色清楚、低饱和关系一致 | 石头因模仿远景雾变成鲜紫色 |
| 可重新打光 | 换光后 Base Color 自然、没有固定亮侧或投影 | 移动灯光后仍有另一方向的画死阴影 |

修订说明写成“位置 + 问题 + 操作”，例如：“柜体四角的圆弧过大，缩小圆角并恢复宽平面；保留包角金属的少量倒角。”

## 按用途检查实际模型

- **共同项**：实际尺寸与单位记录清楚；方向、枢轴、命名和材质分区一致；无意外悬空碎片、反面、穿插或遮住必要开口的封面；可见背面与底部达到使用要求。
- **网格与法线**：读出真实三角面数、顶点数和材质槽数量；检查减面结果是否损伤剪影与设计切面。需要光滑过渡的部位不要强制每三角面硬边，设计中的硬折边也不要全部平均光滑。
- **静态模块**：端面、厚度、连接位置和尺寸可拼接；碰撞按玩法设置，必要时采用简化碰撞。参考图中的剖切展示不自动成为工程模块的缺面。
- **活动道具**：可移动部件独立；枢轴位于真实转轴；打开或旋转时无明显穿插。生成器无法分件时记录后续拆件工作。
- **动画角色**：关节附近拓扑、肢体间隙和衣服结构可用于预定动作；检查绑定、权重与基本变形。仅静态模型时明确“未绑定”。
- **UV 与材质**：根据实际工作流提供 UV/贴图，或说明使用顶点色/调色板材质；检查纹理路径、方向和缺图。Base Color 不含固定灯光，粗糙度和金属度归属正确；AO 若存在则单独标识。
- **引擎检查**：用制作组实际项目导入，检查比例、轴向、材质、法线、碰撞；角色加查骨架和动作。完成后记录实测结果，尚未做则写“未测试”。
